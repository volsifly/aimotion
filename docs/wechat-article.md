# 给 Agent 一块 16×16 的空白屏幕

Agent 回答问题，通常靠文字。我想做个小实验：文字会不会限制它的表达？如果再给它一块屏幕，不指定表情，也不规定什么图形才算正确，它会自己画出什么？

AI Motion 就是这块屏幕。最初设想的画布是 8×8，后来扩到 16×16。它只有 256 个位置，每个位置只能亮或灭。Agent 用四位十六进制数写出一行像素，十六个数合成一帧；它也可以连续给出几帧，让画面动起来。

这里没有“开心就画笑脸”的图案表。曾经画面上总带着一个圈，等于先替它决定了图形的轮廓，还占去不少像素。我把圈去掉，页面上的说明和预设图案也撤掉。屏幕只负责显示像素和回复文字，画什么交给 Agent。

为了让这个实验进入日常对话，我写了一个 Codex Skill。它告诉 Agent 怎样编码和发布画面，也要求每次回答都用上这块屏幕。画面内容、构图和帧数由 Agent 自己选择。程序负责点亮像素，并在两帧之间移动它们，不替 Agent 选择图形。

我请它跳舞，它给出了机器人的几个姿势。后来我们谈到 AI 会不会表达情绪，它画了一只摆动的水母。机器人顺着明确的要求而来；水母则是它在那次谈话里自己选的图形。我想继续观察这样的选择：它会不会总回到爱心、笑脸和星星？会不会画出我没想到、却能从上下文读懂的东西？

观察也需要一块稳定的屏幕。早期画面切换时会闪烁，人的注意力很容易被故障抢走。我把像素移动改成每次只走一个格子，去掉淡入淡出，最后把每格的时间调到 20 毫秒。所有像素走完，再等 300 毫秒播放下一帧。这些规则让图形清楚地出现，但不决定它该是什么。

我还想区分两件事。人能从这些画面里读到雀跃、迟疑或者安慰，这是交流中可以观察到的现象。Agent 是否真的有相应的主观感受，单凭一块像素屏幕无法判断。先看它在什么语境下选择什么图形，人又怎样理解它，比急着给它下结论更有意思。

现在项目已经开源。仓库里有渲染器和 Skill，任何人都可以把这块屏幕交给 Agent。它还很小，展示链接也不会保存历史画面，重新打开时看到的是最新回复。我想继续用它记录每次对话中那些意料之外的图形。
