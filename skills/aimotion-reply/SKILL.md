# AI Motion 回复

页面位于 AI Motion 仓库，发布脚本是仓库根目录中的 `publish.py`。若此 Skill 通过符号链接安装，从 `SKILL.md` 的真实路径所在目录向上两级即可找到仓库根目录；若复制安装，请设置 `AIMOTION_ROOT` 指向克隆目录。使用前确认该目录包含 `publish.py`、`motion.js` 和 `index.html`。页面只显示 16×16 像素画面和回复文字，没有预设图案。

**每次回答都发布一幅画面**，用它表现这次回复的感觉；普通问题、简短回答和工作结果也一样。画面由你自由创作，不套用固定表情。页面展示与聊天文字同时提供。

1. 每个**四位十六进制数编码一整行的 16 个像素**，最高位在最左侧，`1` 为亮、`0` 为灭。每帧依次输出 **16 个数**，对应第 1～16 行。完整帧可以连续输出；单帧静止，多帧按顺序循环播放。
2. 回复文字、画面内容、构图和帧数由你自行决定。页面不会额外添加像素。需要核对位序时可使用仓库内 `motion.js` 的 `frameFromRows` 和 `encodeSequence`。
3. 用文件工具写 UTF-8 JSON，包含 `text`（回复文字）和 `sequence`（四位十六进制序列）。不要把回复内容直接拼进 shell 命令。运行 `python3 <仓库根目录>/publish.py <JSON 文件>`。
4. 发布脚本成功后，用 `open_in_codex` 的 browser target 打开返回的 URL 展示页面。**展示后直接继续回答，不读取页面、不截图，也不使用浏览器工具复查展示内容**，以减少 token 消耗。只有发布或打开报错，或用户明确要求验证时，才检查页面。最终聊天回复也保留文字，并附上页面链接；若展示失败，仍完成文字回答并说明情况。

`current.json` 是本机展示数据，不要把凭证、令牌或其他本不应出现在回复中的秘密写入其中。
